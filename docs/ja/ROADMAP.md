このロードマップは、現在のスコープのローカルキー MVP の目標（画像追跡、CRS/Cloud 認識、メガのみ）を追跡します。

## アクティブ スコープ

アクティブなサンプル ターゲットは意図的に以下に制限されています。

- 画像トラッキング
- CRS/Cloud 認識
- Mega

Hello AR、サーフェス トラッキング、その他の EasyAR サンプルは次のとおりです。現在の目標には含まれていません。

新しいミニ プログラムの焦点は次のとおりです。

- WeChat ミニ プログラム メガ
- WeChat ミニ プログラム CRS / クラウド認識

## 対象範囲の目標の残り

### ターゲット サンプル

- 画像の維持追跡、CRS/Cloud 認識、メガ リリースの証拠をすべての公開プレリリースに合わせて作成します。
- インストール ドキュメント、クライアント受け入れドキュメント、およびスモーク テストを最新の GitHub リリースに合わせて維持します。
- 実際のイメージ トラッキングと CRS プロジェクト ケースを使用して、Unity プログラミング ワークフローの強化を継続します。
 - 公式ローカル サンプル パッケージ、ログインした DevTools、およびテスト ミニ プログラム プロジェクトが利用可能になったら、WeChat 開発者ツール プレビュー/uploadの証拠と `wechat-mega` および `wechat-crs` の実際のデバイスの証拠をキャプチャします。

### 公式 API 統合

スコープ付きローカルキー MVP には、公式 EasyAR アカウント API は必要ありません。後で本番環境の自動化が必要になった場合でも、次のような正式なサービス サポートまたは承認された内部API契約が必要です。

- アカウント ステータス
- ライセンスの検証
- ダウンロード資格とパッケージの検出
- クラウド認識認証情報の検出
- 実際の`EASYAR_API_TOKEN`発行、ローテーション、検証、および失効

これらの API が存在するまでは、ブラウザのハンドオフとローカルの Unity キーが安全なパスです。

### 配布

- GitHub リリースの tarball 配布をローカルキー MVP ユーザーに対して最新の状態に保ちます。
- 本番ゲートが意図的に有効になった後、または別の npm プレリリース ポリシーが承認された後にのみ、npm に公開します。
- リリース ノート、インストール ドキュメント、`easyar-mcp-check`、`npm run github-release:smoke` を最新の公開タグと一致させてください。

### Unity の対象範囲

- サポートされるバージョン範囲が拡張されない限り、検証済みの Unity ベースラインを Unity `2022.3.62f3` に保持します。
- サポートされているプラ​​ットフォームとターゲット サンプルごとに再現可能な証拠を追加します。
- AR の成功には実際のデバイスの証拠を優先します。エミュレータはインストールを検証できます/startupが、カメラベースの追跡の成功を証明することはできません。

## 安全規則

- EasyAR Web サイトのパスワード、確認コード、ライセンス キー、API キー、`appKey`、または `appSecret` をチャットに貼り付けるようにユーザーに求めないでください。
- `ProjectSettings/EasyAR/easyar.local.json`、ランタイム シークレット コピー、APK、Unity パッケージ、署名キー、または資格情報を含むローカル ログをコミットしないでください。
- EasyAR ログイン、ライセンス チェック、ダウンロード認証、エンタープライズ ゲート、またはレート制限をバイパスしないでください。
