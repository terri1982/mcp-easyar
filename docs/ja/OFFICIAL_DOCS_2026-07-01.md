# EasyAR 公式ドキュメントの更新 - 2026 年 7 月 1 日

出典: <https://www.easyar.cn/doc/zh-cn/>

この MCP メタデータの更新は、2026 年 7 月 1 日の EasyAR 中国語公式ドキュメント サイトマップの完全なクロールに基づいています。クロールの範囲は 819 ページでした:

- クラウド API: 19 ページ
- ネイティブ API: 166 ページ
- Unity API: 239 ページ
- WeChat API: 52 ページ
- 開発ガイド: Unity、Native、WeChat、Web、Mega、ヘッドセットのトピックにわたる 247 ページ
- Mega ユーザー ガイド: 95 ページ
- トップレベルのドキュメント索引: 1 ページ

## 現在の公式バージョン

- EasyAR Sense Unity プラグイン: `4003.0.0`
- Mega 用 EasyAR Sense Unity プラグイン: `4003.0.0`
- EasyAR Mega サポート パッケージ: `2.13.0`
- EasyAR Mega Studio (Unity): `2.13.0`
- EasyAR Sense Unity プラグイン拡張機能 / XR デバイス拡張機能パッケージ: `4000.0.1`
- EasyAR Sense ネイティブ: `4.9.0`
- EasyAR Mega WeChat ミニ プログラム プラグイン: `2.0.3`

## MCP-関連する変更

- Unity プラグイン `4003.0.0` では新しいプラグインが導入されています`MegaBlockController` を中心とした Mega 開発ワークフロー。
 - 従来の Unity Mega の前提には注意が必要です。Mega Studio で生成されたノード グループ、マルチブロック構成オプション、および BlockRoot 中心のセットアップは、現在の主要なワークフローではなくなりました。
 - `com.easyar.mega` は現在、Mega サポート パッケージです。 Mega Studio は `com.easyar.mega.studio` に分割されました。
- Mega Studio `2.13.0` は、古い Unity 開発フローをサポートしなくなり、古い Block Viewer ツールを削除しました。
- ドキュメントには、Apple Vision Pro、XREAL Air2 Ultra、PICO 4 Ultra Enterprise、Rokid AR Studio、およびサードパーティ向けの拡張ヘッドセット ガイダンスが含まれるようになりました。ヘッドセット拡張パッケージ。
- Mega オペレーションのドキュメントでは、シーンの更新、フォーマットのアップグレード、新しいマッピング サービスへの移行、オンサイト/simulator 位置入力、データ収集、トラブルシューティングが大きく取り上げられるようになりました。
- Native Sense は `4.9.0` のままです。 WeChat Mega は `2.0.3` のままであるため、MCP はこれらのトラックの新しいバージョンを作成すべきではありません。
