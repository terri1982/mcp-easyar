## セキュリティ

パスワード、確認コード、license key、CRS API KEY / API Secret、`appKey`、`appSecret`、署名キー、秘密情報を含む APK、Unity package、ログをチャットや公開リポジトリへ送信しないでください。MCP は EasyAR または WeChat のログイン、download authorization、license、enterprise gate を回避しません。
