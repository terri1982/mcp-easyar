# mcp-easyar フル目標計画

この計画では、現在リリースされている範囲を維持しながら、元の長期目標を可視化します。

現在の公開リリース: `v0.1.0-local-key.41`

## 目標

登録済み EasyAR ユーザーが Codex、Claude、およびその他の MCP クライアントを使用して以下を行えるようにします。

- インストールと構成`mcp-easyar`
- 公式 EasyAR アカウントとローカル キーのセットアップを安全に完了します
- EasyAR Unity サンプルを構築して実行します
- EasyAR 開発中に Unity プロジェクト プログラミングの支援を受けます

## リリース スライスの完了

承認された集中ターゲットに対する現在のローカル キー MVP が完成しました:

- 画像追跡
- CRS/Cloud 認識
- メガ

証拠:

- GitHub リリース tarball インストール スモーク パス。
- 両方の焦点を絞ったサンプルについて、Android の実デバイスの証拠が存在します。
- `easyar://acceptance/fresh-project` は、新しい Unity プロジェクト受け入れパスを定義します。
- `easyar://workflow/programming` は、安全な Unity プログラミング ワークフローを定義します。
- 実際の公式 EasyAR アカウント API が接続されるまで、本番ゲートは引き続き `Production ready: no` を報告します。

## メガ拡張が完了

 `v0.1.0-local-key.41` プレリリースには Mega が含まれています。証拠には次のものが含まれます:

 - MCP カタログ、Runbook、準備状況チェック、デバイス検証フォーム、MonoBehaviour テンプレート生成、ログ診断には Mega が含まれます。
- Unity 2022.3.62f3 Android APK ビルド、実デバイスのインストール/startup、EasyAR 初期化、Mega Block ロード、 Mega ローカリゼーション/trackingの証拠は、以前に完了したパスから存在します。
- 別の新しい Unity プロジェクトにより、公式 4002 Mega パッケージのインポート、Android APK ビルド/install/startup、EasyAR 初期化、およびオンサイトモードの準備が整っていることが証明されました。
- 安全にコミットされたリリースの証拠には、実際のデバイス APK インストール/startupおよび Mega ローカリゼーション/tracking検証と、選択したマッピング環境からの新規プロジェクトの起動/localization証拠。

## 拡張トラック 1: より多くの EasyAR サンプル

目的: 証拠要件を弱めることなく、現在の 2 つの検証済みサンプルからより公式な EasyAR Unity サンプルに拡張します。

各新しいサンプルのエントリ基準:

- ユーザーがそのサンプル ファミリの続行を明示的に要求します。
- 公式 EasyAR Sense Unity プラグイン バージョンと Unity バージョンが記録されます。
- ローカル ライセンス/API の前提条件がわかっており、文書化されています。
- サンプルには、インポート チェックリスト、プリフライト、実行シーケンス、デバイス検証チェックリスト、実行結果、完了レポート、およびサポートが含まれています。バンドル。

各新しいサンプルの受け入れ基準:

- 公式パッケージ マテリアルからの Unity のインポートが成功する。
- コンパイル チェックに合格する。
- Android または iOS ビルドが成功する。
- サンプルが実証しようとしている AR の動作を実際のデバイスの検証で証明する。
- アカウントのパスワード、ライセンス キー、Cloud Recognition シークレット、署名キー、APK、Unity パッケージ、生のプライベート ログはコミットされません。

候補順序:

1.こんにちは AR: カメラの許可、ARSession の起動、ライセンス/configベースライン。
2.サーフェス トラッキング: 実際のデバイスでのデバイスのトラッキングと配置動作。
3. 前提条件と合格基準が文書化された後の追加の EasyAR Sense Unity プラグイン サンプル。

## 拡張トラック 3: Unity プログラミング サービス

目的: `mcp-easyar` をサンプルの作成だけでなく、EasyAR Unity プロジェクト開発全体で活用できるようにします。

現在のベース:

- 集中プリフライト
- 構成統合監査
- プログラミング コンテキスト
- コードプラン
- C# スクリプトの作成とレビュー
- コンパイル/build/device結果レポート
- コーデックス、クロード、人間用のハンドオフ パック

次の強化ステップ:

- 画像追跡と CRS.
 の実際のプロジェクト ケースをさらに追加します。- より多くのサンプルが検証されると、サンプル固有のプログラミング プレイブックを追加します。
- 生成されたコードは秘密にせず、明示的なプロジェクト目標に範囲を限定してください。

## リリース ポリシー

GitHub プレリリースでは、プロジェクトがローカルキー MVP.
 として明確にラベル付けされている間、引き続き `gate=local-key-mvp` を使用できます。
本番環境の npm 公開は、次のいずれかが true になるまで待機する必要があります:

- 公式 EasyAR アカウント API が接続され、厳格なプロダクション ゲートを通過します
- 明示的なプレリリース npm ポリシーが承認され、パッケージには local-key-only
 というラベルが付けられます。
## 安全境界

`mcp-easyar` は、承認された EasyAR ワークフローをガイドする必要があります。 EasyAR アカウントのログイン、ライセンス チェック、ダウンロード認証、エンタープライズ ゲート、レート制限、またはシークレット処理ルールをバイパスしてはなりません。
