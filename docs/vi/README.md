## Bảo mật

Không gửi mật khẩu, mã xác minh, license key, CRS API KEY / API Secret, `appKey`, `appSecret`, khóa ký, APK, Unity package hoặc log chứa dữ liệu bí mật vào chat hay kho lưu trữ công khai. MCP không vượt qua đăng nhập, quyền tải xuống, license hoặc enterprise gate của EasyAR hay WeChat.
